⭐⭐⭐ Feature 1: write_read_ratio
────────────────────────────────────
Formula:     io_write_bytes_delta / (io_read_bytes_delta + 1.0)
Description: Ratio of bytes written to bytes read per tick
Range:       [0.0 to ∞)
Interpretation:
  - < 1.0    : Process reading more than writing (normal)
  - 1.0–5.0  : Balanced read-write (could be normal or suspicious)
  - > 5.0    : Heavy write bias (HIGH RANSOMWARE SIGNAL)
Ransomware Signal: 
  File encryption requires read (plaintext) → process (AES) → write (ciphertext)
  Result: write_read_ratio often > 10.0 during active encryption


⭐⭐ Feature 2: cpu_x_write
──────────────────────────
Formula:     cpu_percent × io_write_bytes_delta
Description: Product of CPU utilization and write bytes
Range:       [0.0 to large values]
Interpretation:
  - Low:      CPU not busy OR minimal writes (normal)
  - High:     Both CPU and writes are high simultaneously (SUSPICIOUS)
Ransomware Signal:
  AES encryption is CPU-intensive AND produces massive I/O simultaneously
  Result: cpu_x_write spikes during encryption pass


⭐⭐ Feature 3: io_write_intensity
────────────────────────────────────
Formula:     io_write_bytes_delta / (memory_rss_mb × 1024.0 + 1.0)
Description: Write rate normalized by process memory footprint
Range:       [0.0 to large values]
Interpretation:
  - Low:      Writes are small relative to process size (normal)
  - High:     Massive writes from a small-footprint process (SUSPICIOUS)
Ransomware Signal:
  Ransomware stays lean in memory but churns out massive encrypted file writes
  Result: io_write_intensity >> normal processes
